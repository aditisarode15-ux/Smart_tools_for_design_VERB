06 / AI EXPLORATION

AI
EXPANDS.

AI can widen the search space — but the output is still a candidate, not a design decision.

USEFUL

  • Rapid variation
  • Alternative directions
  • Visualisation of possibilities

RISK

  • Geometry drift
  • Style inconsistency
  • False visual confidence
QUESTION: what does the designer need to correct before the output can enter the VERB system?
06 / HUMAN RESOLUTION

HUMAN
RESOLVES.

The designer protects intent, checks coherence and defines what must be validated outside the AI image.

SELECT

  • Preserve VERB grammar
  • Keep affordance explicit
  • Choose useful variation

VALIDATE

  • Proportion
  • Interfaces
  • Engineering / user testing
CORE ASSERTION: OUTPUT ≠ DECISION. Output + critique + human judgement = design evidence.
